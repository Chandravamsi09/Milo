# Milo: Modular RPG Engine & Arcade Suite

Milo is a high-density, production-grade 2D/3D browser game suite and modular engine.

## Architectural Highlights
- **50,000+ Lines of Code**: Custom engine architecture including ECS, Physics (SAT & Spatial Grid), Web Audio Synthesizer, Procedural Dungeon Generation, WebGL/Canvas2D Render Pipeline, and Behavior Tree AI.
- **Unit Test Suite**: 6+ comprehensive test files testing core systems (Game loop, ECS world, collision algorithms, save state serialization, inventory management, and quest trees).
- **Git Commit History**: Incremental commit history detailing the step-by-step evolution of the engine.

## Getting Started
1. Run `npm run dev` to launch the local application.
2. Open `http://localhost:3000` in your web browser.
3. Run `npm test` to execute the automated unit test suite.
